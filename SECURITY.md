# Security

The mods in this repository run as hooks inside Claude Code on your machine, so security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/its-magdy/claude-code-mods/security/advisories/new)
with the affected mod, its version (from its `.claude-plugin/plugin.json`), and steps to reproduce.

You should get a reply within a week. Fixes ship as a new mod version.

## Supported versions

Only the latest version of each mod gets security fixes.
